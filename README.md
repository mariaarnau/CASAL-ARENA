# Casal Arena València – web

Web estática (HTML + CSS + JS, sin dependencias). Abrir `index.html` o servir con `python3 -m http.server`.

## Qué editar
- `data/carta.js` – carta (ahora son **datos de ejemplo**; poner `demo: false` al cargar la real, o `pdf: "assets/carta/carta.pdf"`).
- `data/partidos.js` – partidos del Valencia Basket (**pendiente de verificar** con valenciabasket.com). Los pasados se ocultan solos.
- `data/contacto.js` – dirección, horario y redes sociales (Instagram y TikTok).
- `assets/` – imágenes y vídeo optimizados. `originales/` – material original sin tocar.

Logo: `logo-casal-arena.png` (dorado, para fondos oscuros) y `logo-casal-arena-oscuro.png` (para fondos claros). Ambos transparentes.
